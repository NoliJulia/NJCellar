Syncing Between Devices

  1. On the device with the latest data, tap Export JSON
  2. Save it to iCloud Drive (iOS) or Google Drive (Android) — or AirDrop it
  3. On the other device, tap Import JSON and select that file
  4. Done — your cellar is now in sync
